One Little Font
===============
This editor uses "One Little Font" for the whole interface, the dialogue boxes and exported images.
The font is not bundled (it has its own licence), so add your copy in either way:

1. Easiest: open the app, click "Font" on the Projects page and choose your font file
   (.ttf, .otf, .woff or .woff2). It is remembered in that browser.

2. For everyone who opens your site (for example on GitHub Pages): put the file in this folder
   and name it one of:  OneLittleFont.woff2   OneLittleFont.woff   OneLittleFont.ttf   OneLittleFont.otf
   Then commit it with the rest of the project. Check the font's licence allows web use.
